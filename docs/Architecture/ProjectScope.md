# Enterprise Banking Data Warehouse

## Objective

Build an Enterprise Banking Data Warehouse capable of storing customer, account, transaction, loan, and fraud data.

The system will support:

- Executive Dashboards
- Customer Analytics
- Fraud Analytics
- Loan Analytics
- Branch Performance
- AI-powered Business Insights
